# E10_01 - Display geometry (pure functions)
Role: CODE
Goal: Pure functions for the 1x1..6x6 window sizes.
Prerequisites: E09_04
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_08)
Write only in: crates/puce8gb-desktop/src/display.rs, crates/puce8gb-desktop/src/main.rs (only the line `mod display;`)
## Work
1. New file display.rs. No egui type in it. Constants: `pub const GB_WIDTH: u32 = 160;` `pub const GB_HEIGHT: u32 = 144;` `pub const MIN_SCALE: u32 = 1;` `pub const MAX_SCALE: u32 = 6;`
2. `pub fn clamp_scale(n: u32) -> u32` (0 gives 1, 9 gives 6).
3. `pub fn image_size(scale: u32) -> (u32, u32)` = (160*s, 144*s) with s = clamp_scale(scale).
4. `pub fn scale_label(scale: u32) -> String`: "1x1" .. "6x6" (s = clamp_scale(scale)).
5. `pub fn best_scale(avail_w: f32, avail_h: f32) -> u32`: the largest s in 1..=6 with 160*s <= avail_w and 144*s <= avail_h; 1 when none fits.
6. `pub fn window_size(scale: u32, chrome_h: f32, min_w: f32) -> (f32, f32)` = (max(160*s as f32, min_w), 144*s as f32 + chrome_h).
7. Tests (exact values): clamp_scale(0)=1, (3)=3, (9)=6; image_size(4)=(640,576); scale_label(2)="2x2"; best_scale(800.0,600.0)=4; best_scale(100.0,100.0)=1; best_scale(5000.0,5000.0)=6; window_size(3,60.0,400.0)=(480.0,492.0); window_size(1,60.0,400.0)=(400.0,204.0).
