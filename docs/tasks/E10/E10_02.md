# E10_02 - Settings: window scale and show frame rate
Role: CODE
Goal: Persist window_scale and show_fps in the settings file.
Prerequisites: E10_01
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/settings.rs (whole file); crates/puce8gb-desktop/src/main.rs (grep first: Settings, save_settings, App::new); docs/annexes/decisions.md (A_08)
Write only in: crates/puce8gb-desktop/src/settings.rs, crates/puce8gb-desktop/src/main.rs (only: 2 App fields, their init in App::new from `loaded`, and the Settings literal in save_settings)
## Work
1. settings.rs: add `window_scale: u32` (default 3, UNKNOWN - to confirm) and `show_fps: bool` (default true) to Settings and to its Default.
2. Parse and write them with the SAME line format as the existing `volume` setting (read the file first; keys `scale` and `show_fps`). Scale is passed through display::clamp_scale. An invalid value gives the default. An unknown key is ignored. A missing key gives the default.
3. main.rs: add the 2 fields to App (`window_scale`, `show_fps`), initialise them from the loaded settings in App::new and include them in the Settings literal of save_settings.
4. Tests: round trip of a Settings with scale 5 and show_fps false; scale 0 loads as 1; scale 99 loads as 6; `scale=abc` loads as the default; missing keys give defaults; an unknown key is ignored and does not break the other keys.
