# E10_03 - Window size menu and integer-scaled image
Role: CODE
Goal: View > Window size 1x1..6x6 resizes the window; the image is drawn at an exact integer scale.
Prerequisites: E10_02
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: View menu, texture, TopBottomPanel, CentralPanel, load_texture); crates/puce8gb-desktop/src/display.rs; docs/annexes/decisions.md (A_08)
Write only in: crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/display.rs
## Work
1. display.rs: add `pub fn all_scales() -> [u32; 6]` = [1,2,3,4,5,6] and `pub fn points_for(px: u32, ppp: f32) -> f32` = px as f32 / ppp (ppp <= 0.0 or not finite is treated as 1.0). Tests: all_scales()[5]=6; points_for(640,2.0)=320.0; points_for(160,1.0)=160.0; points_for(160,0.0)=160.0.
2. main.rs: in the View menu add a submenu "Window size" with 6 radio entries labelled with display::scale_label; the selected entry is self.window_scale.
3. Clicking an entry sets self.window_scale, calls save_settings, and sends `egui::ViewportCommand::InnerSize` with display::window_size(scale, self.chrome_h, 480.0) (480.0 = minimum width for the menu bar, UNKNOWN - to confirm visually).
4. Add App field `chrome_h: f32` (initial 60.0): each frame set it to the sum of the heights of the menu bar panel and the status bar panel (response.rect.height() of each panel).
5. Draw the game texture with size = display::image_size(window_scale) converted with points_for(px, ctx.pixels_per_point()), centred, texture option `egui::TextureOptions::NEAREST`.
6. On the first frame send the InnerSize command once for the loaded scale.
