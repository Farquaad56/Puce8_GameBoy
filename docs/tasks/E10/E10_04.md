Role: CODE
Goal: View > Show frame rate toggles the FPS text (status bar and on-screen overlay).
Prerequisites: E10_03
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: FpsCounter, fps, status); crates/puce8gb-desktop/src/display.rs; docs/annexes/decisions.md (A_08)

## Work
1. display.rs: `pub fn fps_text(fps: f32) -> String` = format!("{:.1} FPS", fps); a NaN, infinite or negative value gives "-- FPS". Tests: 59.7 -> "59.7 FPS"; 0.0 -> "0.0 FPS"; 59.94 -> "59.9 FPS"; f32::NAN -> "-- FPS"; -1.0 -> "-- FPS".
2. main.rs: View menu check box "Show frame rate" bound to self.show_fps; a change calls save_settings.
3. When on: keep the FPS text in the status bar and also draw it as an overlay in the top-left corner of the game image (white text, monospace 14, with a 1 px black shadow drawn first at +1,+1). When off: neither is drawn.
4. Use fps_text for both places.
