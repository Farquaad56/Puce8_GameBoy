# E01_02 - Cartridge header parsing
Role: CODE
Goal: Parse and validate the cartridge header.
Prerequisites: E01_01
Read (max 3 files, give line ranges): docs/annexes/notes/07a_cart_header.md (1-150)
Write only in: crates/puce8gb-core/src/media/
## Work
1. `Header` struct: title, cartridge type, ROM size, RAM size, header checksum, validity flags.
2. Implement the header checksum algorithm described in the note; expose `header_checksum_ok`. A bad checksum is reported, not a panic.
3. Reject unknown ROM size codes with LoadError. Keep ROM bytes in the Cartridge.
4. Unit tests with synthetic headers built in the test: good checksum, bad checksum, unknown size code.
