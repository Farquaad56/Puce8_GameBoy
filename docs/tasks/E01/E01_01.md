Role: CODE
Goal: A Dmg value loads a ROM and resets to the post-boot state.
Prerequisites: A_07
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_01..A_06, grep -n then ranges); docs/annexes/notes/08_boot_reset.md (1-150)

4. `reset()` writes the post-boot register and I/O values listed in note 08 for the components that exist so far.
5. Unit tests: valid 32 KiB ROM loads; empty ROM and 100-byte ROM return Err; reset values match note 08.
