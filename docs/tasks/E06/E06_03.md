# E06_03 - Baseline and regression rule
Role: TEST
Goal: Record the baseline score; later changes may not lower it.
Prerequisites: E06_02
Read (max 3 files, give line ranges): docs/annexes/notes/09_test_roms.md (1-150); docs/annexes/decisions.md (A_07)
Write only in: docs/annexes/baseline_score.txt, docs/annexes/open_questions.md
## Work
1. Run the suite, write the passing count to docs/annexes/baseline_score.txt (a single integer).
2. For every failing test: one line in open_questions.md with its probable cause. The user will schedule fix tasks.
3. Print the failing list in the GATE message. The user then runs: python3 docs/tools/task.py addfix "<test name>" for each one to fix.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Name every unit test fn starting with `e06_03_` (the check filters on it).
- Never lower the baseline.
## Exit tests
- file exists: docs/annexes/baseline_score.txt
- suite meets baseline
- cargo fmt --check, clippy -D warnings, cargo test --workspace (added automatically)
- non-regression: all earlier exit tests (run by `done`)
## CLOSURE
python3 docs/tools/task.py check   (repeat until SCORE is full)
python3 docs/tools/task.py done    (commit + push + next task)
GATE after done: print the GATE block of AGENTS.md, then STOP and wait for the user.
