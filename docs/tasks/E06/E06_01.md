# E06_01 - CLI suite runner
Role: CODE
Goal: `suite` runs a manifest of test ROMs and prints a score.
Prerequisites: E05_06
Read (max 3 files, give line ranges): docs/annexes/notes/09_test_roms.md (1-150); docs/annexes/decisions.md (A_07)
Write only in: crates/puce8gb-cli/, docs/annexes/test_manifest.txt
## Work
1. Manifest line format (no dependency): name|dir-pattern|file-prefix|kind|max-cycles|param. Kinds: serial (text), mooneye (register signature), hash (framebuffer hash).
2. `suite [--only NAME] [--baseline FILE]` runs entries, prints one line per test (PASS/FAIL/TIMEOUT) and `SUITE: p/n`; exit 1 if p is below the number in the baseline file.
3. ROMs are found with a recursive search under roms/test-roms by pattern. Missing ROM = FAIL with a clear message.
4. Tests (cargo test in cli crate): manifest parser, baseline comparison, mooneye signature detection on a synthetic program.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Name every unit test fn starting with `e06_01_` (the check filters on it).
- The core is not modified in this task.
## Exit tests
- unit tests e06_01_* pass (at least one)
- cargo fmt --check, clippy -D warnings, cargo test --workspace (added automatically)
- non-regression: all earlier exit tests (run by `done`)
## CLOSURE
python3 docs/tools/task.py check   (repeat until SCORE is full)
python3 docs/tools/task.py done    (commit + push + next task)
