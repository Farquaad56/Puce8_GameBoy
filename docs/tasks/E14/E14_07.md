# E14_07 - Desktop: Boot ROM menu and loading
Role: CODE
Goal: Menu Boot ROM: Enable/Skip, DMG/GBC/SGB files; the DMG boot ROM is used at load and reset.
Prerequisites: E14_06
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/emu.rs (grep first: Command::Load, Reset); crates/puce8gb-desktop/src/main.rs (grep first: load_rom, menu); crates/puce8gb-desktop/src/boot_rom.rs
Write only in: crates/puce8gb-desktop/src/emu.rs, crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/boot_rom.rs
## Work
1. emu.rs: `Command::Load` becomes `Command::Load { rom: Vec<u8>, boot: Option<Vec<u8>> }` (update every sender and the slot code that matches it). With Some(boot) the thread builds the machine with Dmg::with_boot_rom; on error it falls back to Dmg::new and sends the status "Boot ROM rejected, started without it". Command::Reset keeps working (Dmg::reset remaps the boot ROM when one is installed).
2. main.rs: menu "Boot ROM" with two radio entries "Skip boot ROM" and "Enable boot ROM" (saved), then three entries "DMG boot ROM...", "GBC boot ROM...", "SGB boot ROM...". Each opens an rfd file dialog; the file is read and checked with boot_rom::validate; on success its path is stored and saved, on failure the status shows the error. Each entry shows the file name or "(none)" and has a "Clear" button.
3. load_rom: read the DMG boot file when enabled (only the DMG kind is used at this stage: GBC and SGB are used by E15 and E16), call boot_rom::choose, send bytes only for Use, and show the FallbackSkip text in the status bar.
4. Tests (pure): add `pub fn boot_label(path: &str) -> String` in boot_rom.rs returning "(none)" for an empty path and the file name otherwise (use recent::recent_label); tests: "" -> "(none)"; "C:\\x\\dmg_boot.bin" -> "dmg_boot.bin".
