# E14_06 - Desktop: boot ROM settings and validation
Role: CODE
Goal: Two boot ROM paths and the Enable/Skip flag, with validation.
Prerequisites: E14_05
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/settings.rs (whole file); docs/annexes/notes/10_boot_rom.md; docs/annexes/decisions.md (A_11)
Write only in: crates/puce8gb-desktop/src/boot_rom.rs, crates/puce8gb-desktop/src/settings.rs, crates/puce8gb-desktop/src/main.rs, .gitignore
## Work
1. New file boot_rom.rs: `pub enum BootKind { Dmg, Gbc }` (Copy, Debug, PartialEq), `pub fn expected_size(k: BootKind) -> usize` (Dmg 256, Gbc 2304; Gbc UNKNOWN - to confirm in note 10), `pub fn validate(k: BootKind, bytes: &[u8]) -> Result<(), String>` (Err text "boot ROM must be N bytes (got M)").
2. `pub fn choose(enabled: bool, kind: BootKind, bytes: Option<&[u8]>) -> BootChoice` with `pub enum BootChoice { Skip, Use, FallbackSkip(String) }`: not enabled -> Skip; enabled with None -> FallbackSkip("no boot ROM file set"); enabled with invalid bytes -> FallbackSkip(the validate error); valid -> Use.
3. settings.rs: keys `boot_enabled` (on/off, default off), `boot_dmg`, `boot_gbc` (paths, default empty). Same line format as the other settings.
4. .gitignore: add the lines `/boot_roms/` and `*.bootrom` (boot ROMs are never committed, decision A_11).
5. Tests: expected sizes; validate OK and error text for 255 bytes; choose for the 4 cases; settings round trip and defaults (boot_enabled false).
