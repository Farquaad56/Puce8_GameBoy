# E14_04 - Savestate VERSION 2: model and boot flag
Role: CODE
Goal: Add the extension block of decision A_11 to the machine state.
Prerequisites: E14_03
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_05, A_11, A_12); crates/puce8gb-core/src/machine/state.rs (grep first: write_machine_state, read_machine_state); crates/puce8gb-core/src/savestate.rs (grep first: VERSION, HEADER_LEN)
Write only in: crates/puce8gb-core/src/savestate.rs, crates/puce8gb-core/src/machine.rs, crates/puce8gb-core/src/machine/
## Work
1. Add `pub enum Model { Dmg, Cgb }` (derive Copy, Clone, Debug, PartialEq, Eq, Default = Dmg) in machine.rs and `Dmg::model(&self) -> Model` (always Dmg for now: store the field `model`).
2. savestate VERSION becomes 2 (HEADER_LEN unchanged). At the END of the machine state write the extension block: [model u8 (0 Dmg, 1 Cgb)][boot_mapped u8 (0 or 1)]. On load: a model byte > 1 or a boot byte > 1 gives InvalidState; a model different from the machine's gives RomMismatch; boot_mapped = 1 on a machine without a boot ROM installed gives RomMismatch; otherwise it restores boot_mapped. Loads stay atomic.
3. Version 1 states give BadVersion (test with a hand-edited copy of a v2 state).
4. Update ONLY what must change in the existing tests: the expected total sizes (+2 bytes) and the VERSION constant used by e09_01/e09_02/e09_03 tests. Never relax an assertion, never delete a test.
5. New tests: round trip of a machine while the boot ROM is still mapped (after 3 M-cycles of the synthetic boot of E14_03) then both machines run 100 more M-cycles with equal CPU registers; loading that state into a machine without boot ROM gives RomMismatch; model byte 7 (or 2) gives InvalidState and the machine is unchanged; a v1 header gives BadVersion.
