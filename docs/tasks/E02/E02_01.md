# E02_01 - CPU state and micro-op engine
Role: CODE
Goal: Cpu struct and tick() executing NOP, with test helpers.
Prerequisites: E01_04
Read (max 3 files, give line ranges): docs/annexes/notes/02a_cpu_core.md (1-150); docs/annexes/decisions.md (A_03)
Write only in: crates/puce8gb-core/src/cpu/
## Work
1. Registers A F B C D E H L SP PC; 16-bit pair accessors; flag helpers (low nibble of F always 0).
2. Implement the micro-op engine exactly as approved in A_03; `Cpu::tick(&mut self, bus: &mut Bus)` = one bus access.
3. Implement only NOP (and fetch/decode plumbing). All other opcodes behave as NOP for now but must not panic.
4. Add a #[cfg(test)] helper `exec(cpu, bus, &[u8]) -> u32` that places bytes in WRAM, runs to the instruction boundary and returns the M-cycle count.
5. Tests: NOP takes the table cycles, PC advances by 1, F low nibble stays 0.
