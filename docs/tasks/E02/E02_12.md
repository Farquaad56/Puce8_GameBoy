# E02_12 - Serial capture, LY stub, CLI run harness
Role: CODE
Goal: Run a ROM headless and read serial output.
Prerequisites: E02_11
Read (max 3 files, give line ranges): docs/annexes/notes/06_input_serial.md (1-150); docs/annexes/notes/09_test_roms.md (1-150); docs/annexes/decisions.md (A_07)
Write only in: crates/puce8gb-core/src/serial.rs, crates/puce8gb-core/src/video/, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/machine.rs, crates/puce8gb-cli/
## Work
1. Core: SB/SC registers; with internal clock a transfer completes after the note's duration; completed bytes are queued in a fixed buffer; `Dmg::take_serial_output()` drains them.
2. Core: minimal PPU stub: dot counter, LY 0-153 (456 dots per line), VBlank interrupt flag, so ROMs that poll LY run. Full PPU comes in E03.
3. CLI `run <rom> [--max-cycles N] [--frames N] [--expect-serial TEXT] [--trace FILE]`: exit 0 on success, 1 on mismatch, 2 on timeout, 3 on load error. Print the serial text.
4. `--trace FILE` writes one line per instruction: A F B C D E H L SP PC and the 4 bytes at PC, uppercase hex.
5. Tests: serial byte capture, LY wraps at 153, CLI exit codes (cargo test in the cli crate with a tiny synthetic ROM).
