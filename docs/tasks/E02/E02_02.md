Role: CODE
Goal: Cpu::tick() executing NOP through the micro-op engine of A_03, with a test helper.
Prerequisites: E02_01
Read (max 3 files, give line ranges): docs/annexes/notes/02a_cpu_core.md (1-150); docs/annexes/decisions.md (A_03)

## Work
1. Implement the micro-op engine exactly as approved in A_03: `Cpu::tick(&mut self, bus: &mut Bus)` = one bus access.
2. Fetch/decode plumbing, including the CB prefix as a fetch (no CB execution yet).
3. Implement only NOP. Every other opcode behaves as NOP for now but must not panic.
4. Add a #[cfg(test)] helper `exec(cpu, bus, &[u8]) -> u32`: place bytes in WRAM, run to the instruction boundary, return the M-cycle count.
5. Tests: NOP takes the table cycles, PC advances by 1, F low nibble stays 0.
