# E02_11 - Timer
Role: CODE
Goal: DIV, TIMA, TMA, TAC with exact edge behavior.
Prerequisites: E02_10
Read (max 3 files, give line ranges): docs/annexes/notes/01b_timer.md (1-150); docs/annexes/decisions.md (A_01)
Write only in: crates/puce8gb-core/src/timer.rs, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/machine.rs, crates/puce8gb-core/src/lib.rs
## Work
1. Internal 16-bit counter advanced per the clock ratio of A_01; DIV is its upper byte; DIV write resets the counter.
2. TIMA increments on the selected falling edge (including the edge caused by a DIV write or TAC write if the note says so).
3. TIMA overflow: reload and interrupt delay exactly per the note.
4. Wire registers FF04-FF07 on the bus and request the timer interrupt in IF.
5. Tests: all four TAC rates, DIV reset glitch, overflow delay.
