# E02_03 - 8-bit loads
Role: CODE
Goal: All 8-bit load instructions with exact bus accesses.
Prerequisites: E02_02
Read (max 3 files, give line ranges): docs/annexes/notes/02a_cpu_core.md (1-150); docs/annexes/decisions.md (A_03)
Write only in: crates/puce8gb-core/src/cpu/
## Work
1. LD r,r' ; LD r,n ; LD r,(HL) ; LD (HL),r ; LD (HL),n ; LD A,(BC) ; LD A,(DE) ; LD (BC),A ; LD (DE),A.
2. LD A,(nn) ; LD (nn),A ; LDH (n),A ; LDH A,(n) ; LD (C),A ; LD A,(C) ; LD (HL+),A ; LD (HL-),A ; LD A,(HL+) ; LD A,(HL-).
3. One file cpu/instructions/load8.rs. Each instruction is a list of micro-ops, one bus access each.
4. Tests: for every opcode in the group, check registers, memory and the exact M-cycle count against the table.
