# E12_01 - LCD grid filter (pure)
Role: CODE
Goal: Soft pixel-cell grid like a real LCD (BGB look).
Prerequisites: E11_04
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_09)
Write only in: crates/puce8gb-desktop/src/lcd_filter.rs, crates/puce8gb-desktop/src/main.rs
## Work
1. New file lcd_filter.rs, no egui type. Pixels are `[u8; 4]` (RGBA).
2. `pub fn cell_weight(i: u32, scale: u32, strength: u32) -> u32`: if scale <= 1 return 256; c = abs(2*i + 1 - scale) (as i32 then u32); s = min(strength, 255); return 256 - s*c*c/(scale*scale) (integer division).
3. `pub fn grid_filter(src: &[[u8;4]], width: usize, height: usize, scale: u32, strength: u32, gap: [u8;3]) -> Vec<[u8;4]>`: output is (width*scale) x (height*scale), row-major. Each source pixel is replicated scale x scale; for the cell position (ix, iy) inside it: w = (cell_weight(ix)*cell_weight(iy)) >> 8; each of R,G,B = (src*w + gap*(256-w) + 128) >> 8; alpha copied. Return an empty Vec when src.len() != width*height or scale == 0.
4. Tests (exact): cell_weight(0,5,128)=175; (1,5,128)=236; (2,5,128)=256; (3,5,128)=236; (4,5,128)=175; cell_weight(0,1,255)=256; cell_weight(0,2,255)=193; cell_weight(1,2,255)=193.
5. Tests (exact): src = one pixel [200,200,200,255], width 1, height 1, scale 5, strength 128, gap [100,100,100]: output length 25; pixel (x=2,y=2) R=200; pixel (x=0,y=2) R=168; pixel (x=0,y=0) R=146; alpha is 255 everywhere. With scale 1 the output equals the source. A source of the wrong length gives an empty Vec.
