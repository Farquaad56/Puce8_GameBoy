# E12_03 - LcdFilter state and modes
Role: CODE
Goal: One object holds the mode and the previous frame.
Prerequisites: E12_02
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_09)

## Work
1. `pub enum LcdMode { Off, Grid, Ghost }` with `as_str()` -> "off"/"grid"/"ghost" and `from_str(&str) -> LcdMode` (unknown gives Off, case-insensitive).
2. `pub struct LcdFilter { mode, prev: Vec<[u8;4]>, strength: u32, persistence: u32, gap: [u8;3] }`; `new()` = Off, strength 160, persistence 96 (aesthetic, UNKNOWN - to tune), gap [0,0,0]. `set_mode(&mut self, m)` (clears prev), `set_gap(&mut self, gap: [u8;3])`.
3. `pub fn process(&mut self, frame: &[[u8;4]], width: usize, height: usize, scale: u32) -> Option<Vec<[u8;4]>>`: Off -> None. Grid -> Some(grid_filter(...)). Ghost -> blend with prev (when prev is empty or has another length use the frame as is), store the blended frame (before the grid) as prev, then grid_filter.
4. Tests: Off gives None; Grid on a 2x2 frame at scale 3 gives 36 pixels; Ghost first frame equals the Grid output of the same frame; Ghost second call with a different frame differs from plain Grid of that frame; set_mode clears prev (next Ghost call equals plain Grid); from_str/as_str round trip and from_str("???") = Off.
