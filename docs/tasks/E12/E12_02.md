# E12_02 - LCD ghosting blend (pure)
Role: CODE
Goal: Pixel response: blend the previous frame into the current one.
Prerequisites: E12_01
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_09)
Write only in: crates/puce8gb-desktop/src/lcd_filter.rs
## Work
1. `pub fn ghost_blend(prev: &[[u8;4]], cur: &[[u8;4]], persistence: u32) -> Vec<[u8;4]>`: p = min(persistence, 255); each of R,G,B = (cur*(256-p) + prev*p + 128) >> 8; alpha copied from cur. When prev.len() != cur.len() return cur.to_vec().
2. Tests (exact): cur=[200,200,200,255], prev=[100,100,100,255], p=128 -> R=150; p=0 -> R=200 (identity); prev empty -> returns cur; alpha stays 255.
