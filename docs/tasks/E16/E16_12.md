# E16_12 - Core: PAL_TRN and PAL_SET
Role: CODE
Goal: System palette RAM and palette selection.
Prerequisites: E16_11
Read (max 3 files, give line ranges): docs/annexes/notes/12b_sgb_graphics.md
Write only in: crates/puce8gb-core/src/sgb/palette.rs, crates/puce8gb-core/src/sgb/mod.rs
## Work
1. Sgb field `system_pal: Vec<u16>` (2048 entries = 512 palettes of 4 colors). PAL_TRN data (4096 bytes, little endian words, high bit masked) fills it.
2. PAL_SET (id $0A): bytes 1-8 = four palette numbers (16 bit little endian, 0..=511, higher values masked or ignored per the note) selecting system palettes for active palettes 0-3; byte 9: bit 7 apply an attribute file (the ATTR_SET behaviour of E16_13, call it when it exists, until then ignore), bit 6 cancel the mask (E16_14), bits 0-5 the file number.
3. Tests (exact): PAL_TRN data where word k = k for k in 0..2048; PAL_SET numbers [3, 0, 511, 1] gives pal0 colors 1-3 = [13, 14, 15], pal2 colors 1-3 = [2045, 2046, 2047], pal1 colors 1-3 = [1, 2, 3], pal3 colors 1-3 = [5, 6, 7]; a palette number 600 does not panic (behaviour per the note, assert no change of the other palettes).
