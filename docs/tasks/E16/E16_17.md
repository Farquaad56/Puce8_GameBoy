## Work

2. With no border data received yet the border area is black.
3. Tests (exact): sgb_frame length is 57344 (256*224); pixel (48,40) equals game pixel (0,0); pixel (47,40) is a border pixel (differs from the game pixel when the border is a known test color); pixel (207,183) equals game pixel (159,143); pixel (208,184) is a border pixel; output_size is (256,224) for Sgb with border, (160,144) with border off and for Dmg and Cgb.
