# E16_22 - Desktop: Super Game Boy menu entry and border display
Role: CODE
Goal: System > Super Game Boy works, with a border toggle and 256x224 images.
Prerequisites: E16_21
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: frame, texture, scale, System menu); crates/puce8gb-desktop/src/emu.rs (grep first: frame, send); crates/puce8gb-desktop/src/display.rs
Write only in: crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/emu.rs, crates/puce8gb-desktop/src/display.rs, crates/puce8gb-desktop/src/settings.rs, crates/puce8gb-desktop/src/system.rs
## Work
1. display.rs: generalise the geometry: `image_size_for(base_w: u32, base_h: u32, scale: u32) -> (u32, u32)` and `window_size_for(base_w: u32, base_h: u32, scale: u32, chrome_h: f32, min_w: f32) -> (f32, f32)`; the old functions call them with 160x144. Tests (exact): image_size_for(256,224,3) = (768,672); image_size_for(160,144,4) = (640,576); window_size_for(256,224,2,60.0,400.0) = (512.0,508.0); window_size_for(160,144,1,60.0,400.0) = (400.0,204.0).
2. emu.rs: the thread sends the picture of Dmg::sgb_frame with its size (Dmg::output_size) for Sgb, the normal frame otherwise; the frame message carries (width, height). Update the receiver in main.rs.
3. main.rs: enable the "Super Game Boy" entry in the System menu; View menu check box "SGB border" (saved as setting `sgb_border`, default on) sending Dmg::set_sgb_border through a new Command::SgbBorder(bool). The window size menu uses the current base size (256x224 or 160x144) and resizes the window when the base size changes. LCD shader and window scale work on the current base size.
4. The DMG palette menu is disabled (hover text "not used in Super Game Boy mode") while the loaded model is Sgb.
5. Tests: SystemChoice::Sgb still round trips; base_size_for(model: Model, border: bool) -> (u32,u32) in system.rs: (Sgb,true) = (256,224), (Sgb,false) = (160,144), (Cgb,true) = (160,144), (Dmg,true) = (160,144).
