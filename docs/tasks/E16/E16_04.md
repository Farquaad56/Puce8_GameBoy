# E16_04 - Core: SGB packet receiver
Role: CODE
Goal: Decode 16-byte packets from the JOYP write sequence.
Prerequisites: E16_03
Read (max 3 files, give line ranges): docs/annexes/notes/12a_sgb_protocol.md; crates/puce8gb-core/src/sgb/mod.rs
Write only in: crates/puce8gb-core/src/sgb/packet.rs, crates/puce8gb-core/src/sgb/mod.rs
## Work
1. `pub struct PacketReceiver` (Default) with `pub fn push(&mut self, value: u8) -> Option<[u8; 16]>`: a reset pulse starts a packet (and restarts a packet in progress); then 128 data bits, least significant bit of byte 0 first; then the stop bit; after the stop bit the full packet is returned. The written values for 0, 1, reset, idle and stop are those of note 12a (do not invent them).
2. A helper for tests `fn encode(packet: &[u8; 16]) -> Vec<u8>` (in the test module) producing the write sequence of the note: the sequence length is 2 (reset) + 128*2 (bits) + 2 (stop) = 260 writes.
3. Tests: encode then push every value: only the last push returns Some and it equals the packet; two different packets in a row both decode; a reset pulse in the middle of a packet drops the partial data and the next full packet decodes; idle writes ($30) before the reset pulse change nothing; a packet of 16 zero bytes decodes.
