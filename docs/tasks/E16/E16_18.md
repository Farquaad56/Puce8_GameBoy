# E16_18 - Core: ignored SGB commands
Role: CODE
Goal: Accepted-and-ignored commands never panic and never change the picture.
Prerequisites: E16_17
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_14); docs/annexes/notes/12a_sgb_protocol.md
Write only in: crates/puce8gb-core/src/sgb/mod.rs, crates/puce8gb-core/src/sgb/command.rs
## Work
1. Commands SOUND $08, SOU_TRN $09, ATRC_EN $0C, TEST_EN $0D, ICON_EN $0E, DATA_SND $0F, DATA_TRN $10, JUMP $12 and OBJ_TRN $18 are accepted and ignored: Sgb field `ignored_count: u32` increments. An id above $18 increments `unknown_count: u32`. Neither changes palettes, attributes, mask or border.
2. Tests: for each ignored id, a packet leaves a snapshot of (pal, attr, mask mode, border_map) unchanged and ignored_count grows by one; id $19 and $7F grow unknown_count; a 3-packet DATA_SND does not leave the assembler stuck (the next command works).
