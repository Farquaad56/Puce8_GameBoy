# E16_15 - Core: CHR_TRN (border tiles)
Role: CODE
Goal: Decode 4-bit border tiles.
Prerequisites: E16_14
Read (max 3 files, give line ranges): docs/annexes/notes/12b_sgb_graphics.md
Write only in: crates/puce8gb-core/src/sgb/border.rs, crates/puce8gb-core/src/sgb/mod.rs
## Work
1. CHR_TRN (id $13): byte 1 bit 0 = tiles 0-127 (0) or 128-255 (1); bit 1 = BG or OBJ tile set (follow the note: store BG tiles only, ignore OBJ). The 4096 bytes are 128 tiles of 32 bytes: bytes 0-15 hold bit planes 0 and 1 (one pair of bytes per row), bytes 16-31 bit planes 2 and 3; the leftmost pixel is bit 7.
2. Sgb field `border_tiles: Vec<u8>` (256 tiles * 64 pixels, values 0-15).
3. Tests (exact): in tile 0, row 0 bytes: byte 0 = $80 (plane 0), byte 1 = $00, byte 16 = $80 (plane 2), byte 17 = $00 -> pixel (0,0) = 5 and pixel (1,0) = 0; the same data sent with bit 0 = 1 fills tile 128, tile 0 keeps its previous content; an all-zero transfer clears the 128 tiles it covers.
