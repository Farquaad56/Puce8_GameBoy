## Work
1. ATTR_BLK (id $04): byte 1 = number of data sets; each set is 6 bytes: control (bit 0 inside, bit 1 border line, bit 2 outside), palette designation (bits 0-1 inside, bits 2-3 border, bits 4-5 outside), X1, Y1, X2, Y2 in cells. Follow the note for the border-line and the inside/outside interplay rules when only some control bits are set. A command spans several packets when 2 + 6*n > 16 (n >= 3); coordinates outside 0..=19 / 0..=17 are clamped (never panic).
2. Tests: one set, control $01 (inside only), inside palette 2, rect (5,5)-(10,10): cell (7,7) = 2, cell (0,0) = 0, cell (15,15) = 0; one set, control $04 (outside only), outside palette 3 (designation byte $30): cell (0,0) = 3 and cell (7,7) = 0 for a rect (5,5)-(10,10); a command with 3 sets (2 packets) applies all 3; X2 = 200 does not panic.
