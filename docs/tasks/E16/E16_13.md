# E16_13 - Core: ATTR_TRN and ATTR_SET
Role: CODE
Goal: 45 stored attribute files and their selection.
Prerequisites: E16_12
Read (max 3 files, give line ranges): docs/annexes/notes/12b_sgb_graphics.md
Write only in: crates/puce8gb-core/src/sgb/attr.rs, crates/puce8gb-core/src/sgb/mod.rs
## Work
1. Sgb field `attr_files: Vec<u8>` (45 * 90 = 4050 bytes, filled from the first 4050 bytes of an ATTR_TRN transfer). One file = 18 rows of 5 bytes, 4 cells per byte, first (leftmost) cell in bits 7-6.
2. ATTR_SET (id $16): byte 1 bits 0-5 = file number (0..=44, larger values ignored), bit 6 = cancel mask (E16_14). Applying a file copies its 360 cells into the attribute map.
3. Tests (exact): file 0 row 0 byte 0 = $E4 and ATTR_SET 0: cells (0,0),(1,0),(2,0),(3,0) = 3,2,1,0; file 44 is the last file (bytes 3960..4049) and can be applied; ATTR_SET 45 changes nothing; ATTR_TRN data shorter than expected cannot occur (always 4096 bytes).
