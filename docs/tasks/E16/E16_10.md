# E16_10 - Core: ATTR_LIN, ATTR_DIV, ATTR_CHR
Role: CODE
Goal: Line, division and character attribute commands.
Prerequisites: E16_09
Read (max 3 files, give line ranges): docs/annexes/notes/12b_sgb_graphics.md
Write only in: crates/puce8gb-core/src/sgb/attr.rs
## Work
1. ATTR_LIN (id $05): byte 1 = count, then one byte per line (bits 0-4 line number, bits 5-6 palette, bit 7 direction: per the note which value is a row and which a column).
2. ATTR_DIV (id $06): byte 1 = palettes and direction, byte 2 = line number; follow the note for which side gets which palette.
3. ATTR_CHR (id $07): start X, start Y, count (16 bit), direction, then 2 bits per cell, 4 cells per byte, first cell in the highest bits (verify in the note); wrapping at the map end per the note.
4. Tests (exact where stated): ATTR_LIN with one entry byte $C3 (line 3, palette 2, bit 7 set) applies palette 2 to the whole row 3 or column 3 as the note says for bit 7 = 1 (assert one cell on the line and one off it); two entries; ATTR_DIV on line 9 with palettes (1 above, 2 below, 3 on the line) per the note layout; ATTR_CHR starting at (0,0) horizontal with data byte $E4 gives cells 0-3 = palettes 3,2,1,0; a count that runs past the map end does not panic.
