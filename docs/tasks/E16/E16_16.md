# E16_16 - Core: PCT_TRN (border map and palettes)
Role: CODE
Goal: Decode the border tile map and border palettes.
Prerequisites: E16_15
Read (max 3 files, give line ranges): docs/annexes/notes/12b_sgb_graphics.md
Write only in: crates/puce8gb-core/src/sgb/border.rs, crates/puce8gb-core/src/sgb/mod.rs
## Work
1. PCT_TRN (id $14): the 4096 bytes hold the border map (32 x 28 entries of 16 bits: tile number, palette, flips per note) and the border palettes at the offset of the note. Decode into `border_map: Vec<BorderCell>` (`BorderCell { tile: u8, palette: u8, flip_x: bool, flip_y: bool }`) and `border_pal: [[u16; 16]; 3]` or the shape of the note.
2. Build the test blocks by hand from the layout of note 12b (write the layout offsets as constants with the note fact id in a comment).
3. Tests: an entry with tile 5, palette 1, no flip decodes to those fields; an entry with the X flip bit set decodes flip_x = true and flip_y = false; the first palette entry colors decode as little endian words; a block of 4096 zero bytes decodes to tile 0 everywhere and does not panic.
