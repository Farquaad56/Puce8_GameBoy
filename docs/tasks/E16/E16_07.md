Role: CODE
Goal: The four active palettes set by packets.
Prerequisites: E16_06

## Work
1. Sgb field `pal: [[u16; 4]; 4]` (RGB555). Default for all four = [0x7FFF, 0x56B5, 0x294A, 0x0000] (white, light grey, dark grey, black: UNKNOWN - to confirm the real default, aesthetic choice).
2. PAL01 sets palettes 0 and 1, PAL23 palettes 2 and 3, PAL03 palettes 0 and 3, PAL12 palettes 1 and 2. Packet layout: color 0 (shared), then colors 1-3 of the first palette, then colors 1-3 of the second; each color is 2 bytes little endian (the high bit is masked off). Color 0 is copied to all four palettes (the shared backdrop rule of the note: verify).
3. Tests (exact): a PAL01 packet with bytes [header $01, FF 7F, 1F 00, E0 03, 00 7C, 01 00, 02 00, 03 00, 00] gives pal0 = [0x7FFF,0x001F,0x03E0,0x7C00] and pal1 = [0x7FFF,0x0001,0x0002,0x0003]; a following PAL23 packet with color 0 = 0x0000 sets pal2/pal3 colors 1-3 as sent and color 0 of all four palettes becomes 0 (if the note says so); PAL03 and PAL12 target the right palettes (use distinct colors); a color word $FFFF is stored as $7FFF.
