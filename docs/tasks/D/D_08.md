Role: DOC
Goal: Write the note docs/annexes/notes/03b_io_registers.md.
Prerequisites: D_07
Read (max 3 files, give line ranges): refs/pandocs (grep + small ranges only)

## Work
1. Locate sources in refs/pandocs: Hardware Registers, Memory Map. Use grep -rn -i, then sed -n 'a,bp' on small ranges.
2. Extract the facts for: every register FF00-FFFF: address, name, R/W, unused bits read as 1, side effects, power-up value. Use ONE table; keep Source lines per group of registers.
3. Write docs/annexes/notes/03b_io_registers.md in French, paraphrased, using the fact format of AGENTS.md (Fait/Source/Fiabilite/Impact code/Statut).
4. Every number has a Source line (file#section). Missing info: Statut UNKNOWN - to confirm + line in open_questions.md.
5. Two sources disagree: Statut CONFLIT, both values, and name the test ROM that decides.
6. Max 150 lines. If it does not fit, keep what the code needs and list what you left out in the last lines.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Paraphrase only; at most a few quoted words per source.
- No Rust code in this task.
## Exit tests
- note is valid (<=150 lines, >=4 facts with Source and Statut, no TODO)
- non-regression: all earlier exit tests (run by `done`)
