# D_04 - Opcode table (generated, verified)
Role: DOC
Goal: Produce a verified SM83 opcode table as Rust const data, generated from the committed JSON table.
Prerequisites: D_03
Read (max 3 files, give line ranges): docs/annexes/seed/Opcodes.json (NEVER open it: ~11000 lines, use python3 one-liners) + refs/pandocs (grep + small ranges, only for the spot checks)
Write only in: docs/annexes/code/, docs/annexes/notes/02c_cpu_opcodes_src.md
## Work
1. The machine-readable table already exists: docs/annexes/seed/Opcodes.json (source: gbdev gb-opcodes, https://gbdev.io/gb-opcodes/Opcodes.json). Do NOT ask the user anything, do NOT use the network.
2. Inspect its shape without opening it, for example:
   python3 -c "import json;d=json.load(open('docs/annexes/seed/Opcodes.json'));print(list(d),len(d['unprefixed']),len(d['cbprefixed']))"
   python3 -c "import json;d=json.load(open('docs/annexes/seed/Opcodes.json'));print(d['unprefixed']['0x20'])"
   Expected shape: two tables "unprefixed" and "cbprefixed", keys "0x00".."0xFF"; each entry has mnemonic, bytes, cycles, operands, flags {Z,N,H,C}.
3. Facts about the JSON to respect (verify each with a one-liner before relying on it):
   - cycles are T-cycles. Convert to M-cycles by dividing by 4 (assert every value is divisible by 4).
   - cycles has 1 value (fixed cost) or 2 values [branch taken, branch not taken]. One value => taken = not taken.
   - cbprefixed cycles already include the 0xCB prefix fetch (register op = 2 M, (HL) op = 4 M, BIT n,(HL) = 3 M). Never add the PREFIX entry (0xCB in unprefixed, 1 M) on top.
   - Illegal opcodes have mnemonic ILLEGAL_xx. Expected: 11 in unprefixed (D3 DB DD E3 E4 EB EC ED F4 FC FD), 0 in cbprefixed. The JSON gives them 1 M-cycle but real hardware locks up: flag them illegal, do not rely on that cost.
   - flags values: "-" unchanged, "0", "1", or the letter itself (Z, N, H, C) meaning computed by the instruction.
4. Write docs/annexes/code/gen_opcodes.py (stdlib only, reads the JSON, writes docs/annexes/code/opcodes.rs, re-runnable, deterministic). Build the mnemonic text from mnemonic + operands: an operand with immediate false is written in parentheses, increment => "+" and decrement => "-" after the name (HL+ / HL-), operands joined by ",". Special case 0xF8 must read "LD HL,SP+e8". Check JP HL, LDH (C),A, LDH (a8),A, LD (a16),SP in the output.
5. Generated file docs/annexes/code/opcodes.rs (ASCII only, header comment "generated by gen_opcodes.py from seed/Opcodes.json, do not edit"):
   pub struct OpInfo { pub mnemonic: &'static str, pub bytes: u8, pub m_taken: u8, pub m_not_taken: u8, pub z: &'static str, pub n: &'static str, pub h: &'static str, pub c: &'static str, pub illegal: bool }
   pub const OPCODES: [OpInfo; 256]    (index = opcode)
   pub const CB_OPCODES: [OpInfo; 256] (index = opcode after 0xCB)
   No Rust logic, no allocation, no dependency. Make sure the entries are in index order 0x00..0xFF.
6. Verify, by script where possible (put the checks in gen_opcodes.py as assertions):
   - 256 entries in each table; illegal count = 11 and the list matches step 3.
   - generated file is pure ASCII.
   - spot-check 10 opcodes BY HAND against refs/pandocs (grep + small sed ranges): 0x00, 0x20, 0x34, 0x76, 0xC0, 0xCD, 0xE8, 0xF8 and CB 0x06, CB 0x46. Compare bytes, M-cycles, flags. A value pandocs does not show: Statut UNKNOWN - to confirm.
   - a mismatch between pandocs and the JSON: Statut CONFLIT, both values, decide with a test ROM (cpu_instrs / instr_timing from the Blargg suite, if present in roms/test-roms).
7. Write docs/annexes/notes/02c_cpu_opcodes_src.md in French, fact format of AGENTS.md (Fait/Source/Fiabilite/Impact code/Statut). Source = seed/Opcodes.json (gbdev gb-opcodes, date of the commit that added it) and the pandocs file#section used for each spot check. Fiabilite of the JSON: communautaire. Facts to record: T- vs M-cycles, taken/not-taken order, CB prefix cost included, illegal opcodes (list), flags notation, spot-check results.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- The generated file is later copied without reading. It must be correct now.
- Never open the JSON or opcodes.rs whole (150 lines rule): use python one-liners, grep -c, sed -n 'a,bp', head.
- Total cycles are not enough: record bytes and cycles; bus-access order is derived in E02.
- Write nothing in docs/annexes/seed/ (read only for this task).
