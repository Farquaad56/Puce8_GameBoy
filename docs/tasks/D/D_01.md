Role: DOC
Goal: List every usable source file and which note it feeds.
Prerequisites: E00_03
Read (max 3 files, give line ranges): refs/pandocs (ls, wc -l)
Write only in: docs/annexes/sources_inventory.md
## Work
1. List the Pan Docs files: find refs/pandocs -name '*.md' | head -80, with wc -l for each.
2. List the test ROM suites present in roms/test-roms (directories only, one line each) and read the README of the repo (sed -n '1,80p') to see how each suite signals pass/fail.
3. Write a table in docs/annexes/sources_inventory.md: file or suite | type | lines | topics | reliability | feeds note (01_timing, 02a_cpu_core, ...).
4. Keep the commit/date header written by E00_02.
5. List topics for which no source exists in a section 'Manquants' and add each to open_questions.md.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Do not copy documentation text. Titles and line counts only.
## Exit tests
- table present
- at least 15 rows
- non-regression: all earlier exit tests (run by `done`)
