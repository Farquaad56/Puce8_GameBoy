# E00_03 - CI workflow and repo hygiene
Role: CODE
Goal: Add a CI workflow that runs fmt, clippy and tests.
Prerequisites: E00_02
Read (max 3 files, give line ranges): none
Write only in: .github/, README.md
## Work
1. Create .github/workflows/ci.yml: on push and pull_request; ubuntu-latest; stable toolchain; steps cargo fmt --check, cargo clippy --workspace --all-targets -- -D warnings, cargo test --workspace.
2. The workflow must NOT download or use any ROM (roms/ is not in the repo).
3. README.md: 5 lines in French: project goal, how to build, where the docs are (docs/README.md).
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Name every unit test fn starting with `e00_03_` (the check filters on it).
- No secret in any file. No token in the workflow.
## Exit tests
- file exists: .github/workflows/ci.yml
- CI runs clippy
- file exists: README.md
- cargo fmt --check, clippy -D warnings, cargo test --workspace (added automatically)
- non-regression: all earlier exit tests (run by `done`)
## CLOSURE
python3 docs/tools/task.py check   (repeat until SCORE is full)
python3 docs/tools/task.py done    (commit + push + next task)
GATE after done: print the GATE block of AGENTS.md, then STOP and wait for the user.
