# E00_01 - Cargo workspace with three crates
Role: CODE
Goal: Create the Cargo workspace; three crates build and test.
Prerequisites: none
Read (max 3 files, give line ranges): none
Write only in: Cargo.toml, rust-toolchain.toml, .gitignore, crates/
## Work
1. Root Cargo.toml: [workspace] resolver 2, members crates/puce8gb-core, crates/puce8gb-cli, crates/puce8gb-desktop.
2. rust-toolchain.toml: channel stable, components rustfmt and clippy.
3. puce8gb-core: lib.rs with #![forbid(unsafe_code)], NO dependency, pub fn version() -> &'static str, one unit test e00_01_version.
4. puce8gb-cli and puce8gb-desktop: main.rs printing the version; both depend on the core. No eframe/cpal/gilrs yet.
5. .gitignore must contain target/, roms/ and refs/.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- Name every unit test fn starting with `e00_01_` (the check filters on it).
- Do not add any dependency to the core, ever.
## Exit tests
- workspace builds
- unit tests e00_01_* pass (at least one)
- core forbids unsafe
- roms/ ignored
- cargo fmt --check, clippy -D warnings, cargo test --workspace (added automatically)
- non-regression: all earlier exit tests (run by `done`)
