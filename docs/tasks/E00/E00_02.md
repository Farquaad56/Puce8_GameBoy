# E00_02 - Fetch Pan Docs and test ROMs
Role: DOC
Goal: Get the documentation and test ROMs locally (outside git).
Prerequisites: E00_01
Read (max 3 files, give line ranges): none
Write only in: refs/, roms/, docs/annexes/sources_inventory.md
## Work
1. Run: git clone --depth 1 https://github.com/gbdev/pandocs refs/pandocs
2. Run: git clone --depth 1 https://github.com/c-sp/game-boy-test-roms roms/test-roms
3. If roms/test-roms has no .gb files, read its README (head -60) for the release archive. Ask the user ONE question: to download and unzip it into roms/test-roms.
4. If a clone fails (network), call task.py blocked with the error. Do not invent files.
5. Write at the top of docs/annexes/sources_inventory.md: the two URLs, `git rev-parse HEAD` of each, and today's date (use `date +%F`).
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm.
- refs/ and roms/ are git-ignored. Never commit ROMs.
## Exit tests
- pandocs present
- test ROMs present
- inventory records commits
- non-regression: all earlier exit tests (run by `done`)
