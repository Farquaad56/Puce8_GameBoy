# E13_01 - ROM check (pure header inspection)
Role: CODE
Goal: Inspect a ROM image before it is sent to the core.
Prerequisites: E12_04
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/rom_info.rs (whole file); docs/annexes/decisions.md (A_10)
Write only in: crates/puce8gb-desktop/src/rom_check.rs, crates/puce8gb-desktop/src/main.rs
## Work
1. New file rom_check.rs. `pub enum Severity { Error, Warning }`, `pub struct RomIssue { pub severity: Severity, pub message: String }`, `pub struct RomReport { pub title: String, pub cart_type: u8, pub rom_size_declared: usize, pub rom_size_actual: usize, pub ram_size: usize, pub cgb_flag: u8, pub sgb_flag: u8, pub header_checksum_ok: bool }`.
2. `pub fn inspect(bytes: &[u8]) -> (Option<RomReport>, Vec<RomIssue>)`. Fewer than 0x150 bytes: (None, one Error "ROM too small (N bytes)"). Otherwise a report built from the header: title via crate::rom_info::rom_title, $0143 cgb_flag, $0146 sgb_flag, $0147 cart_type, $0148 declared size = 32768 << code (code 0..=8; other codes: declared 0 plus a Warning), $0149 RAM size (0 none, 2 = 8192, 3 = 32768, 4 = 131072, 5 = 65536, others 0 plus a Warning).
3. Header checksum: x = 0; for each byte b of $0134..=$014C inclusive: x = x.wrapping_sub(b).wrapping_sub(1); it must equal the byte at $014D. A mismatch gives a Warning "header checksum mismatch" and header_checksum_ok=false. A declared size different from the actual length gives a Warning "declared size N differs from file size M".
4. `pub fn issue_text(issue: &RomIssue) -> String`: "Error: <message>" or "Warning: <message>".
5. Tests: helper `make_rom(title: &[u8], size_code: u8, len: usize) -> Vec<u8>` that writes the title at $0134, the size code at $0148 and the correct checksum at $014D. An all-zero header ($0134..=$014C) has checksum $E7; the title bytes b"TEST" at $0134 give checksum $A7. A good 32768-byte ROM (code 0) gives no issue and header_checksum_ok. Corrupting byte $0134 gives the checksum Warning. 0x100 bytes gives the Error and None. Code 1 (declared 65536) with 32768 bytes gives the size Warning. issue_text of an Error starts with "Error: ".
