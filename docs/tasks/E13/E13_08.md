# E13_08 - ROM info window
Role: CODE
Goal: View > ROM info shows the header of the loaded ROM.
Prerequisites: E13_07
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: load_rom, View menu); crates/puce8gb-desktop/src/rom_check.rs
Write only in: crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/rom_check.rs
## Work
1. rom_check.rs: `pub fn report_lines(r: &RomReport) -> Vec<(String, String)>` with exactly these labels in order: "Title", "Cartridge type" (format "$XX" two hex digits upper case), "ROM size" (format "N KiB"), "RAM size" ("none" when 0, else "N KiB"), "Color flag" ("$XX"), "Super Game Boy flag" ("$XX"), "Header checksum" ("OK" or "BAD").
2. Tests: for a report with title "TEST", cart_type 0x13, rom_size_actual 65536, ram_size 8192, cgb_flag 0x80, sgb_flag 0x03, checksum ok: the 7 pairs are [("Title","TEST"),("Cartridge type","$13"),("ROM size","64 KiB"),("RAM size","8 KiB"),("Color flag","$80"),("Super Game Boy flag","$03"),("Header checksum","OK")]; with ram_size 0 the RAM line is "none".
3. main.rs: keep the RomReport of the last loaded ROM in App (`rom_report: Option<RomReport>`); View menu entry "ROM info" opens an egui::Window with a two-column grid of report_lines; with no ROM it shows "No ROM loaded".
