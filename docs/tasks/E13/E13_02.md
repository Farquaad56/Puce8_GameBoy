# E13_02 - Recent ROM list (pure)
Role: CODE
Goal: Most recent ROMs first, without duplicates.
Prerequisites: E13_01
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_10)
Write only in: crates/puce8gb-desktop/src/recent.rs, crates/puce8gb-desktop/src/main.rs
## Work
1. New file recent.rs. `pub const MAX_RECENT: usize = 10;` `pub struct RecentList { items: Vec<String> }` with Default.
2. `push(&mut self, path: &str)`: removes an equal entry, inserts at the front, truncates to MAX_RECENT. An empty or whitespace-only path is ignored.
3. `remove(&mut self, path: &str)`, `clear(&mut self)`, `items(&self) -> &[String]`.
4. `to_lines(&self) -> Vec<String>` and `from_lines(lines: &[String]) -> RecentList` (blank lines skipped, duplicates removed keeping the first, at most MAX_RECENT).
5. `pub fn recent_label(path: &str) -> String`: the file name only (text after the last '/' or '\\'); the whole text when there is no separator.
6. Tests (exact): push a,b,c then a -> items [a,c,b]; 12 distinct pushes keep 10 and the newest first; push("  ") changes nothing; remove(b) works; from_lines(["x","","y","x"]) = [x,y]; recent_label("H:\\roms\\tetris.gb") = "tetris.gb"; recent_label("/a/b/zelda.gbc") = "zelda.gbc"; recent_label("plain.gb") = "plain.gb".
