# E13_03 - Settings: recent ROMs and last folder
Role: CODE
Goal: Persist the recent list and the last used folder.
Prerequisites: E13_02
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/settings.rs (whole file); crates/puce8gb-desktop/src/recent.rs
Write only in: crates/puce8gb-desktop/src/settings.rs, crates/puce8gb-desktop/src/main.rs (only: App fields recent and last_dir, init from `loaded`, save_settings literal)
## Work
1. settings.rs: new field `recent: Vec<String>` and `last_dir: String` (default empty). Keys: one `recent=<path>` line per entry (in order) and `last_dir=<path>`. Use the same line format as the other settings. Repeated `recent` keys must be accepted by the parser (read how the parser handles keys first).
2. Paths contain no newline; a value is taken as the text after the first '=' (a path may contain '=').
3. main.rs: App fields `recent: RecentList` (built with RecentList::from_lines) and `last_dir: String`; written back in save_settings.
4. Tests: round trip with 3 recent entries keeps the order; a path containing '=' survives; more than 10 lines load as 10; missing keys give an empty list and an empty last_dir.
