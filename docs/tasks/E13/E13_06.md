# E13_06 - Load pipeline uses the ROM check
Role: CODE
Goal: Errors and warnings are shown before the ROM reaches the core.
Prerequisites: E13_05
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: load_rom); crates/puce8gb-desktop/src/rom_check.rs; docs/annexes/decisions.md (A_10)
Write only in: crates/puce8gb-desktop/src/rom_check.rs, crates/puce8gb-desktop/src/main.rs
## Work
1. rom_check.rs: `pub enum LoadDecision { Load, LoadWithWarning(String), Reject(String) }` and `pub fn decide(bytes: &[u8]) -> LoadDecision`: any Error issue gives Reject(text of the first Error); else warnings give LoadWithWarning (all warning texts joined with "; "); else Load.
2. Tests: a good ROM (use make_rom) gives Load; a ROM with a wrong checksum gives LoadWithWarning containing "checksum"; 0x100 bytes gives Reject starting with "Error: ROM too small".
3. main.rs load_rom: after reading the file call decide. Reject: status shows the text, nothing is sent to the emulation thread, the current game keeps running. LoadWithWarning: load as today, then set the status to the warning text. Load: as today.
