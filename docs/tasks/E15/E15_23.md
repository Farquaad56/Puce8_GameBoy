# E15_23 - Desktop: Emulate system menu (Game Boy / Game Boy Color)
Role: CODE
Goal: Menu System: Auto, Game Boy, Game Boy Color (no Super Game Boy).
Prerequisites: E15_22
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: load_rom, Command::Load, menu); crates/puce8gb-desktop/src/emu.rs (grep first: Command::Load); crates/puce8gb-desktop/src/boot_rom.rs
Write only in: crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/emu.rs, crates/puce8gb-desktop/src/settings.rs, crates/puce8gb-desktop/src/boot_rom.rs, crates/puce8gb-desktop/src/system.rs
## Work
1. New file system.rs: `pub enum SystemChoice { Auto, Dmg, Cgb }` with `as_str()` ("auto","dmg","cgb"), `from_str` (unknown, "sgb" included -> Auto) and `pub fn resolve(choice: SystemChoice, rom: &[u8]) -> puce8gb_core::Model` (Auto uses puce8gb_core::auto_model; Dmg/Cgb map directly) and `pub fn label(choice) -> &'static str` ("Auto", "Game Boy", "Game Boy Color").
2. settings.rs: key `system` stored with as_str, default auto.
3. boot_rom.rs: `pub fn kind_for(model: puce8gb_core::Model) -> BootKind` (Dmg -> Dmg, Cgb -> Gbc).
4. emu.rs: Command::Load gains `model: puce8gb_core::Model`; the thread builds the machine with Dmg::with_config(MachineConfig { model, boot_rom }). Update every sender.
5. main.rs: menu "System" with radio entries Auto, Game Boy, Game Boy Color (no Super Game Boy entry). The choice is saved; it applies at the next ROM load or reset (show that in a hover text). load_rom resolves the model, picks the boot kind with kind_for, and uses the matching boot ROM path of the settings (boot_gbc for Cgb). The status bar shows the model label after loading.
6. Tests: as_str/from_str round trip and "???" -> Auto; resolve(Auto, rom with $0143=$80) = Cgb; resolve(Auto, rom with $0143=$00) = Dmg; resolve(Dmg, rom with $0143=$C0) = Dmg; kind_for for the two models.
