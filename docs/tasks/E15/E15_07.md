# E15_07 - Core: VRAM bank 1 (VBK $FF4F)
Role: CODE
Goal: Second 8 KiB VRAM bank on the Cgb model.
Prerequisites: E15_06
Read (max 3 files, give line ranges): crates/puce8gb-core/src/bus.rs (grep first: vram, read, write, mode 3 blocking); crates/puce8gb-core/src/video/mod.rs (grep first: vram); docs/annexes/notes/11a_cgb_regs.md
Write only in: crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/bus/, crates/puce8gb-core/src/video/
## Work
1. Cgb: VBK bit 0 selects the bank seen by the CPU at $8000..=$9FFF; reading $FF4F returns the unused bits as the note says. The PPU gets read access to both banks (an accessor `vram_bank(&self, bank: usize, addr: u16) -> u8`, used by E15_10/E15_11).
2. VRAM blocking during mode 3 applies to both banks.
3. Tests: write $AA at $8000 in bank 0 and $BB in bank 1, read each back by switching VBK; the PPU accessor returns both values; on the Dmg model VBK writes change nothing and $8000 keeps one bank.
