# E15_08 - Core: palette RAM (BCPS/BCPD/OCPS/OCPD)
Role: CODE
Goal: CGB color palette registers.
Prerequisites: E15_07
Read (max 3 files, give line ranges): crates/puce8gb-core/src/bus.rs (grep first: io, write); docs/annexes/notes/11b_cgb_video.md

## Work
1. Two arrays of 64 bytes (BG and OBJ palette RAM). BCPS/OCPS: bits 0-5 index, bit 7 auto-increment (a write to BCPD/OCPD increments the index after the write when set); the read value of unused bit 6 per the note. BCPD/OCPD read and write the byte at the index.
2. Access blocking in mode 3 per the note (UNKNOWN - to confirm exact read value; follow the note).
3. Initial content of the BG palette RAM for Cgb without boot ROM per the note (UNKNOWN: use $FF for every byte and add a line in open_questions.md).
4. Tests: write index 0 with auto-increment, write $1F then $00: byte0 = $1F, byte1 = $00, index is now 2; without auto-increment the index stays; index wraps from 63 to 0; BG and OBJ RAM are independent; on the Dmg model these registers are not present.
