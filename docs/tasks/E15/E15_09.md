# E15_09 - Core: RGB555 to pixel conversion
Role: CODE
Goal: Convert a CGB palette entry to the framebuffer pixel.
Prerequisites: E15_08
Read (max 3 files, give line ranges): crates/puce8gb-core/src/video/mod.rs (grep first: framebuffer, dmg_palette); docs/annexes/notes/11b_cgb_video.md; docs/annexes/decisions.md (A_13)
Write only in: crates/puce8gb-core/src/video/
## Work
1. `pub fn rgb555_to_rgb888(lo: u8, hi: u8) -> [u8; 3]`: value = lo | (hi << 8) (little endian); r5 = value & 31, g5 = (value >> 5) & 31, b5 = (value >> 10) & 31; each channel c8 = (c5 << 3) | (c5 >> 2). No color correction (decision A_13: plain expansion; a correction option may come later).
2. `pub fn rgb555_to_pixel(lo: u8, hi: u8) -> P` building the same pixel type as the DMG path (P of E11_01) from those 3 channels.
3. Tests (exact): (lo=$FF, hi=$7F) -> [255,255,255]; (0,0) -> [0,0,0]; (lo=$1F, hi=0) -> [255,0,0]; (lo=$E0, hi=$03) -> [0,255,0]; (lo=0, hi=$7C) -> [0,0,255]; value $0010 (r5=16) -> [132,0,0]; value $0001 (r5=1) -> [8,0,0]; the high bit 15 is ignored: (lo=$FF, hi=$FF) -> [255,255,255].
