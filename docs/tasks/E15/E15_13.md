# E15_13 - Core: DMG compatibility mode on the Cgb model
Role: CODE
Goal: A DMG-only cartridge on the Cgb model renders like the DMG path with the chosen DMG palette.
Prerequisites: E15_12
Read (max 3 files, give line ranges): crates/puce8gb-core/src/machine.rs (grep first: cgb); crates/puce8gb-core/src/video/mod.rs; docs/annexes/notes/11b_cgb_video.md; docs/annexes/decisions.md (A_13)
Write only in: crates/puce8gb-core/src/machine.rs, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/video/
## Work
1. `compat: bool` on the machine/bus: true when model is Cgb and the cartridge byte $0143 has bit 7 clear. In compat mode: the DMG rendering path is used (BGP/OBP0/OBP1 then the dmg_palette table of E11_01), the CGB attributes and VBK bank 1 are not used by the renderer, OPRI reads and acts as 1 (DMG priority). Palette RAM writes are accepted but have no visual effect.
2. This is a deliberate simplification: the real boot ROM picks colors by a title hash table (decision A_13); here the user's DMG palette is used instead.
3. Tests: using the synthetic ROM helper of crates/puce8gb-core/src/machine/determinism.rs (grep first), the framebuffer hash after 10 frames is identical for Model::Dmg and Model::Cgb on a ROM with $0143 = $00; a ROM with $0143 = $80 on Model::Cgb is NOT in compat mode (compat() false); Model::Dmg is never compat.
