## Work
1. `pub struct MachineConfig { pub model: Model, pub boot_rom: Option<Vec<u8>> }` (Default = Dmg, no boot ROM) and `Dmg::with_config(rom: &[u8], cfg: MachineConfig) -> Result<Dmg, MachineError>`. Dmg::new and Dmg::with_boot_rom call it. `Dmg::model()` returns the configured model. The expected boot ROM length depends on the model (Dmg 256, Sgb 256, Cgb 2304, UNKNOWN - to confirm in note 10): add `Model::boot_rom_len(self) -> usize`.
2. `pub fn auto_model(rom: &[u8]) -> Model`: Cgb when the byte at $0143 has bit 7 set, else Dmg (never Sgb). A ROM shorter than $0144 bytes gives Dmg. Export Model, MachineConfig and auto_model at the crate root (lib.rs) so the frontends can use them.
3. Guard: write_machine_state returns Err(StateError::InvalidState) when the model is not Dmg (temporary, removed by E15_19 and E16_17; leave a comment naming them).
4. Tests: auto_model for $0143 = $00 -> Dmg, $80 -> Cgb, $C0 -> Cgb, $42 -> Dmg, a 0x100-byte slice -> Dmg; with_config(Cgb) reports model() == Cgb; with_config(Dmg) behaves exactly as Dmg::new (same CPU registers); saving a Cgb machine gives InvalidState and a Dmg machine still saves.
