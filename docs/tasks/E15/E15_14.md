# E15_14 - Core: HDMA general-purpose transfer
Role: CODE
Goal: FF51-FF55 general-purpose DMA to VRAM.
Prerequisites: E15_13
Read (max 3 files, give line ranges): crates/puce8gb-core/src/bus.rs (grep first: oam dma, dma); docs/annexes/notes/11c_cgb_speed_dma.md; docs/annexes/decisions.md (A_01)
Write only in: crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/bus/, crates/puce8gb-core/src/machine.rs
## Work
1. Registers: $FF51 source high, $FF52 source low (low 4 bits ignored), $FF53 destination high (only bits 0-4 used), $FF54 destination low (low 4 bits ignored). Source = (hi << 8 | lo) & $FFF0; destination = $8000 | ((hi << 8 | lo) & $1FF0). The destination VRAM bank is the one selected by VBK.
2. $FF55 write with bit 7 = 0 starts a general-purpose transfer of ((value & $7F) + 1) * 16 bytes; the CPU is stalled for the transfer and the timing per 16-byte block is the one of the note (UNKNOWN: if the note gives no value use 8 M-cycles per block at normal speed and add a line in open_questions.md). Reading $FF55 after the end returns $FF.
3. Tests (exact addresses): source regs $C1,$23 -> source $C120; destination regs $01,$2F -> destination $8120... (check: ((0x01<<8)|0x2F) & 0x1FF0 = 0x0120 -> $8120); length value $03 -> 64 bytes copied from $C120.. to $8120..; a block of 16 bytes (value $00) copies exactly 16 bytes and not 17; the byte after the last one is untouched; after the end FF55 reads $FF.
4. Dmg model: these registers do nothing.
