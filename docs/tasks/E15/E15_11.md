# E15_11 - Core: sprite attributes and OPRI
Role: CODE
Goal: Sprites use bank, palette and the priority mode on the Cgb model.
Prerequisites: E15_10
Read (max 3 files, give line ranges): crates/puce8gb-core/src/video/mod.rs (grep first: sprite, oam, line_sprites); docs/annexes/notes/11b_cgb_video.md

## Work
1. Cgb color mode: OAM attribute bit 3 selects the tile data bank, bits 0-2 the OBJ palette number (OBJ palette RAM, same formula as E15_10); the DMG palette bit 4 is ignored.
2. OPRI ($FF6C) bit 0: 0 = priority by OAM index (CGB style), 1 = priority by X coordinate (DMG style); the read value of the unused bits per the note; Cgb without boot ROM: initial value per the note.
3. Tests: a sprite with bit 3 set takes its data from bank 1; palette number 2 selects OBJ palette 2; two overlapping sprites with OPRI=0: the lower OAM index wins even when its X is larger; with OPRI=1 the smaller X wins; write/read OPRI round trip.
