# E15_18 - Core: RP and undocumented registers
Role: CODE
Goal: $FF56, $FF72-$FF75 and PCM12/PCM34 as the notes describe them.
Prerequisites: E15_17
Read (max 3 files, give line ranges): crates/puce8gb-core/src/bus.rs (grep first: io, FF7); docs/annexes/notes/11c_cgb_speed_dma.md
Write only in: crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/bus/
## Work
1. $FF56 RP: store the writable bits and return the read value per the note (no infrared link is emulated: the receive bit reads as 'no signal').
2. $FF72 and $FF73: plain read/write bytes. $FF74: read/write on Cgb in color mode only (per the note). $FF75: only bits 4-6 are writable, the rest reads 1.
3. $FF76 and $FF77 (PCM12 and PCM34): read-only; if the notes do not give how to compute them return 0 and add one line in open_questions.md (UNKNOWN - to confirm).
4. Tests: write/read round trips with the masks above; a write to $FF76 does not change the read value; on the Dmg model all these addresses keep today's read value.
