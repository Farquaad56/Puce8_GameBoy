# E15_16 - Core: KEY1 and the STOP speed switch
Role: CODE
Goal: FF4D arm bit, current speed, STOP toggles the speed.
Prerequisites: E15_15
Read (max 3 files, give line ranges): crates/puce8gb-core/src/cpu/ (grep first: stop, STOP); crates/puce8gb-core/src/bus.rs (grep first: io); docs/annexes/notes/11c_cgb_speed_dma.md
Write only in: crates/puce8gb-core/src/cpu/, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/bus/, crates/puce8gb-core/src/machine.rs
## Work
1. KEY1 ($FF4D): bit 0 = armed (R/W), bit 7 = current speed (read only: 1 = double). Unused bits read as in the note. On the Dmg model the register is not present.
2. When STOP executes with the armed bit set on Cgb: the speed toggles, the armed bit clears, the CPU does not enter low power (per the note), DIV is reset and the switch delay of the note applies (UNKNOWN: if the note gives no value, switch immediately and add a line in open_questions.md). STOP with the bit clear keeps today's behaviour.
3. Tests: write 1 to KEY1, run STOP: bit 7 reads 1 and bit 0 reads 0; run STOP again without arming: speed unchanged; Dmg model: STOP behaves as before; the speed flag is a field (state saving is E15_19).
