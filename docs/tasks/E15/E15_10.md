# E15_10 - Core: background and window attributes
Role: CODE
Goal: BG/window tiles use bank 1 attributes (palette, bank, flips) on the Cgb model.
Prerequisites: E15_09
Read (max 3 files, give line ranges): crates/puce8gb-core/src/video/mod.rs (grep first: fetch, tile, fifo); docs/annexes/notes/11b_cgb_video.md; docs/annexes/decisions.md (A_13)
Write only in: crates/puce8gb-core/src/video/
## Work
1. When the machine is Cgb and in color mode (compat mode is E15_13), the fetcher reads the attribute byte from VRAM bank 1 at the same map address as the tile number: bits 0-2 BG palette number, bit 3 tile data bank, bit 5 X flip, bit 6 Y flip, bit 7 BG priority (stored in the FIFO entry for E15_12). The pixel color comes from BG palette RAM (palette*8 + color*2) through rgb555_to_pixel.
2. The Dmg model and the DMG path are bit-for-bit unchanged (framebuffer hash tests unchanged).
3. Tests on a synthetic frame (VRAM filled by the test): tile 1 row 0 data lo=$80 hi=$00 in bank 0 (color id 1 at the leftmost pixel); attribute 0 -> pixel x=0 has color id 1 and x=7 id 0; attribute bit 5 (X flip) -> color id 1 at x=7; attribute bit 3 with the same data only in bank 1 -> found; attribute palette 3 with BG palette 3 entry 1 = $1F,$00 -> the pixel is [255,0,0]; Y flip uses row 7 of the tile (put the data in row 7 for this test).
