# E15_06 - Core: WRAM banking (SVBK $FF70)
Role: CODE
Goal: 32 KiB WRAM in 8 banks of 4 KiB on the Cgb model.
Prerequisites: E15_05
Read (max 3 files, give line ranges): crates/puce8gb-core/src/bus.rs (grep first: wram, echo, read, write); docs/annexes/notes/11a_cgb_regs.md; docs/annexes/decisions.md (A_13)
Write only in: crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/bus/
## Work
1. On Cgb: $C000..=$CFFF is bank 0, $D000..=$DFFF is the bank selected by SVBK bits 0-2, where a written value 0 selects bank 1. The echo area follows the same mapping. Other models keep 8 KiB WRAM exactly as today.
2. SVBK read value and unused bits per the note.
3. Tests: write $11 in bank 1 at $D000, select bank 2, write $22 at $D000, select bank 1, read $11; selecting 0 reads the same data as 1; $C000 is unaffected by SVBK; the echo address $F000 mirrors $D000 of the current bank; on the Dmg model $FF70 is not a register (a write does not change $D000 data).
