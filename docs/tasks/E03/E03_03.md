# E03_03 - Background pixel pipeline (no fine scroll, no window)
Role: CODE
Goal: Mode 3 with fetcher and FIFO for the background, with SCX multiple of 8 and no window. Output into a line buffer of color indexes.

## Hardware spec (fixed by the project)
This is a project decision: do NOT search the notes for what is written here and do NOT discuss it. If a line elsewhere contradicts this section, this section wins. If a note is longer than 150 lines, use grep -n on the keywords of the task and read only the matching ranges. Do not read more than 3 files.
- Dots: 456 dots per line, 154 lines, 70224 dots per frame. One M-cycle = 4 dots. Lines 0..143 are visible, lines 144..153 are VBlank (mode 1).
- Modes on a visible line: mode 2 = dots 0..79, mode 3 starts at dot 80 and lasts between 172 and 289 dots, mode 0 is the rest of the line.
- LCDC bits: 7 LCD enable, 6 window tile map (0 = 0x9800, 1 = 0x9C00), 5 window enable, 4 BG and window tile data (1 = 0x8000 unsigned, 0 = base 0x9000 with signed index), 3 BG tile map (0 = 0x9800, 1 = 0x9C00), 2 sprite size (0 = 8x8, 1 = 8x16), 1 sprite enable, 0 BG and window enable.
- A tile is 16 bytes, 2 bytes per row: first byte = low bit plane, second byte = high bit plane, bit 7 is the leftmost pixel. Color index = (high bit << 1) | low bit.
- Background pixel Y = (LY + SCY) and 0xFF. Tile row index = Y / 8, line inside the tile = Y mod 8. BG tile map base from LCDC bit 3. Tile data from LCDC bit 4 (unsigned from 0x8000, or signed index from 0x9000).
- LCDC bit 0 = 0: the background color index is 0.
- In this task only SCX values that are multiples of 8 are tested (fine scroll is E03_11).
## Work
1. Pixel fetcher steps and the FIFO as described in note 04b. One pixel leaves the FIFO per dot when allowed, into `line_buf: [u8; 160]` (color index 0..3, before any palette).
2. Tile map and tile data addressing as in the spec; the fetcher reads VRAM directly (not through the CPU blocking).
3. Replace the constant MODE3_LEN of E03_01 by the real end condition: mode 3 ends when 160 pixels were output, then mode 0 starts. With SCX mod 8 = 0, no window and no sprite, mode 3 must last 172 dots.
4. Tests: pixels of a known tile (colors 0..3 on a row), 0x8000 and signed addressing, map select, SCY wrap, SCX coarse scroll, mode 3 lasts 172 dots.
