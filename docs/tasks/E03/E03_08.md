# E03_08 - LYC, STAT register and STAT interrupt line

## Hardware spec (fixed by the project)
This is a project decision: do NOT search the notes for what is written here and do NOT discuss it. If a line elsewhere contradicts this section, this section wins. If a note is longer than 150 lines, use grep -n on the keywords of the task and read only the matching ranges. Do not read more than 3 files.
- STAT read: bit 7 = 1, bits 6..3 = interrupt select bits as written, bit 2 = coincidence flag (LY == LYC), bits 1..0 = current mode. STAT write: only bits 6..3 are writable.
- STAT interrupt line = (bit6 AND coincidence) OR (bit5 AND mode == 2) OR (bit4 AND mode == 1) OR (bit3 AND mode == 0).
- IF bit 1 is set only on a 0 -> 1 transition of that line (blocking: while the line stays high no new request).
- Special cases (line 144 mode 2 quirk, STAT write quirk, exact LYC compare dot) only if the note documents them; otherwise write a comment UNKNOWN - to confirm and do not implement them.
## Work
1. LYC register read/write at 0xFF45. Coincidence flag updated as the note says.
2. STAT register at 0xFF41 per the spec above (mode bits come from E03_01).
3. STAT line with edge detection: keep the previous line value in a field, compare after each step.
4. Tests: flag set and cleared when LY == LYC, STAT write masks bits 2..0 and 7, each of the four sources raises IF bit 1 once, two overlapping sources raise it once, a new request after the line fell.
