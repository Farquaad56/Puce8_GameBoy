## Hardware spec (fixed by the project)
This is a project decision: do NOT search the notes for what is written here and do NOT discuss it. If a line elsewhere contradicts this section, this section wins. If a note is longer than 150 lines, use grep -n on the keywords of the task and read only the matching ranges. Do not read more than 3 files.
- LCD on: VRAM (0x8000..0x9FFF) cannot be accessed by the CPU in mode 3: reads return 0xFF, writes are ignored.
- LCD on: OAM (0xFE00..0xFE9F) cannot be accessed in modes 2 and 3: reads return 0xFF, writes are ignored.
- VBlank (mode 1) and mode 0: free access. LCD off: free access.
- The PPU's own reads are never blocked. The DMA interaction is task E03_15.
- Exact dot boundaries where the mode change becomes visible: only if the note gives them; otherwise use the mode bits and write UNKNOWN - to confirm.
## Work
1. In the bus read and write paths for VRAM and OAM, ask the Ppu whether the access is allowed (a small `pub(crate) fn vram_accessible(&self) -> bool` and `oam_accessible`).
2. Tests: each mode for VRAM and for OAM (read value 0xFF, write ignored, then allowed again), LCD off allows everything.
