# E03_07 - dmg-acid2 and framebuffer hash
Role: TEST
Goal: Deterministic frame hash and image dump for visual validation.
Prerequisites: E03_06
Read (max 3 files, give line ranges): docs/annexes/notes/09_test_roms.md (1-150); docs/annexes/decisions.md (A_07)
Write only in: crates/puce8gb-cli/, crates/puce8gb-core/src/video/
## Work
1. CLI: `run <rom> --frames N --hash` prints a 64-bit FNV-1a hash of the framebuffer; `--dump-ppm FILE` writes a binary PPM.
2. Run dmg-acid2 for the number of frames given in the note, dump docs/annexes/acid2.ppm (ignored by the check).
3. Fix PPU bugs revealed by the image only by finding the hardware cause in the notes.
4. The GATE message asks the user to open the PPM and compare it with the reference image. Golden hash is recorded only after approval.
