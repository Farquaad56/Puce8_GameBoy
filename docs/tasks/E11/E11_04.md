# E11_04 - Palette menu
Role: CODE
Goal: View > Palette: presets and a custom 4-color editor.
Prerequisites: E11_03
Read (max 3 files, give line ranges): crates/puce8gb-desktop/src/main.rs (grep first: View menu, window, egui::Window); crates/puce8gb-desktop/src/palettes.rs
Write only in: crates/puce8gb-desktop/src/main.rs, crates/puce8gb-desktop/src/palettes.rs
## Work
1. View menu submenu "Palette": first entry "Default" (CoreDefault), then one radio entry per PRESETS item, then "Custom..." which opens an egui::Window with 4 single-line text fields (shade 0 lightest .. shade 3 darkest) and an Apply button.
2. palettes.rs: `pub fn validate_custom(fields: &[String; 4]) -> Result<[u32; 4], usize>`: Ok with the 4 colors, or Err(index of the first invalid field). Tests: 4 valid fields -> Ok; the third invalid -> Err(2); empty field -> Err(index).
3. In the window an invalid field is drawn with a red text color; Apply is disabled until all 4 are valid. Apply sets PaletteChoice::Custom, sends Command::Palette and saves the settings.
4. Selecting any entry sends Command::Palette (CoreDefault sends nothing and tells the user the change applies at the next ROM load: status message, UNKNOWN - to confirm if the core can restore its default: if Dmg::set_dmg_palette accepts the old constants, send them instead).
