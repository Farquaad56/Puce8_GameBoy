# E11_02 - Desktop: palette presets and color parsing
Role: CODE
Goal: Pure data and parsing for palettes.
Prerequisites: E11_01
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_09)
Write only in: crates/puce8gb-desktop/src/palettes.rs, crates/puce8gb-desktop/src/main.rs (only the line `mod palettes;`)
## Work
1. New file palettes.rs, no egui type. `pub struct Preset { pub name: &'static str, pub colors: [u32; 4] }` (colors are 0xRRGGBB, index 0 = lightest shade) and `pub const PRESETS: [Preset; 4]`: ("Grayscale", FFFFFF AAAAAA 555555 000000), ("Classic green", 9BBC0F 8BAC0F 306230 0F380F), ("Pocket", C4CFA1 8B956D 4D533C 1F1F1F), ("Kirby light", E0F8D0 88C070 346856 081820). These are aesthetic choices, not hardware facts.
2. `pub fn preset_index(name: &str) -> Option<usize>` (case-insensitive, trimmed).
3. `pub fn parse_hex_color(text: &str) -> Option<u32>`: trim, optional leading '#', exactly 6 hex digits (upper or lower case), else None.
4. `pub fn format_hex_color(c: u32) -> String` = "#RRGGBB" upper case.
5. `pub fn parse_palette(text: &str) -> Option<[u32; 4]>` (4 colors separated by commas) and `pub fn format_palette(p: [u32; 4]) -> String` (colors joined by commas).
6. Tests (exact): parse_hex_color("#9BBC0F")=Some(0x9BBC0F); ("9bbc0f")=Some(0x9BBC0F); ("#9BBC0")=None; ("GGGGGG")=None; ("#9BBC0F00")=None; format_hex_color(0x0F380F)="#0F380F"; PRESETS[0].colors=[0xFFFFFF,0xAAAAAA,0x555555,0x000000]; preset_index(" classic GREEN ")=Some(1); preset_index("nope")=None; parse_palette(format_palette(PRESETS[3].colors))=Some(PRESETS[3].colors); parse_palette with 3 colors = None.
