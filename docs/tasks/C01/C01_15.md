# C01_15 - Minimal LY / VBlank stub
Role: CODE
Goal: A dot counter and LY readable at $FF44 so ROMs that poll the screen line do not hang.
Prerequisites: C01_14
Read (max 3 files, give line ranges): docs/annexes/notes/01_timing.md (grep first); docs/annexes/notes/05_video_regs.md or the note listing LY (grep -l "LY" docs/annexes/notes/*.md); docs/annexes/decisions.md (A_01 only)
Write only in: crates/puce8gb-core/src/video/, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/machine.rs
## Work
1. In video/: dot counter and LY; line length and last LY from note 01_timing / A_01 (grep, never from memory). Advance one dot per Machine::tick().
2. The VBlank bit of IF is raised at the documented moment, once per frame. LY readable at $FF44, writes ignored.
3. This is a STUB: the full PPU is epic E03. Keep it small and replaceable. Do not draw anything.
4. Tests: LY wraps at the documented last line; VBlank flag raised once per frame; LY visible through bus.read($FF44).
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm (open_questions.md).
- Name every unit test fn starting with `c01_15_` (the check filters on it).
- One tick = one M-cycle = AT MOST ONE bus access (decision C_00). Hardware arithmetic with wrapping_* only. No allocation in tick().
- A test is changed only if it contradicts the notes, never to make it pass. Never disable a test.
- cpu/registers.rs may only get ADDED helpers: its e02_01_ tests must keep passing.
- FORBIDDEN: a test that ticks a REAL opcode of another group and expects it to be unimplemented (it breaks when that group is implemented and `done` replays old checks). To test the unimplemented path use `record_unimplemented` directly (core tests) or `Cpu::debug_set_unimplemented` (other crates). "Implement ONLY the LIST" means: write no code for other opcodes, not: write tests for them.
