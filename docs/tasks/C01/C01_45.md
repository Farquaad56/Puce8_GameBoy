## Work
1. In run.rs add (copy this skeleton, adapt only if it does not compile):
```rust
use std::io::Write;

pub const FAIL_MARKER: &str = "Failed";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Scan { Continue, Found, Failed }

pub fn scan_serial(collected: &mut String, new_bytes: &[u8], expect: Option<&str>) -> Scan {
    collected.push_str(&String::from_utf8_lossy(new_bytes));
    if let Some(text) = expect {
        if collected.contains(text) {
            return Scan::Found;
        }
    }
    if collected.contains(FAIL_MARKER) {
        return Scan::Failed;
    }
    Scan::Continue
}
```
2. Outcome: remove `Copy` from its derive (keep Debug, Clone, PartialEq, Eq) and add two variants `Found(String)` and `Failed(String)` (the collected serial text). Fix the existing c01_44_ tests only where the compiler requires it (e.g. pass `&outcome`). Do not weaken them.
3. In run_rom, create before the loop `let mut collected = String::new(); let mut buf = [0u8; 64];`. After the 4 inner ticks of each M-cycle add:
```rust
let n = dmg.take_serial_output(&mut buf);
if n > 0 {
    print!("{}", String::from_utf8_lossy(&buf[..n]));
    let _ = std::io::stdout().flush();
    match scan_serial(&mut collected, &buf[..n], args.expect_serial.as_deref()) {
        Scan::Found => return Outcome::Found(collected),
        Scan::Failed => return Outcome::Failed(collected),
        Scan::Continue => {}
    }
}
```
(`take_serial_output` is a method of the `Machine` trait, already imported in run.rs.)
4. exit_code: Found => 0; Failed => 1; MaxCycles => 2 if args.expect_serial is Some, else 0; LoadError => 3 (unchanged).
