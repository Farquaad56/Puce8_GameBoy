# C01_02 - Dmg drives the CPU: one M-cycle every 4 dots
Role: CODE
Goal: Dmg::tick() advances a dot counter and calls cpu.tick(&mut bus) once every 4 dots.
Prerequisites: C01_01
Read (max 3 files, give line ranges): docs/annexes/decisions.md (A_01 and C_00 only); docs/annexes/notes/01_timing.md (grep first)
Write only in: crates/puce8gb-core/src/machine.rs
## Work
1. Add a private dot phase counter (0..3) to Dmg. On every `Machine::tick()`: when the phase wraps to 0, call `self.cpu.tick(&mut self.bus)` exactly once (M-cycle = 4 dots, note 01_timing / A_01; grep the number, do not write it from memory).
2. reset() clears the phase. Integer arithmetic only. No allocation.
3. Tests: after 4 * N ticks of a ROM full of unknown opcodes the CPU has fetched N bytes (PC = $0100 + N); 3 ticks do not advance PC; reset restarts the phase.
