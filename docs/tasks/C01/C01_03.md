# C01_03 - Serial capture (SB/SC) in the bus
Role: CODE
Goal: Bytes sent through the serial port are captured so test ROMs can print on it.
Prerequisites: C01_02
Read (max 3 files, give line ranges): docs/annexes/notes/06_input_serial.md (grep first); docs/annexes/decisions.md (A_07 only)
Write only in: crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/machine.rs
## Work
1. Add a fixed buffer to Bus (`[u8; 256]` + length, no Vec). A write to SC ($FF02) with bit 7 set AND bit 0 set (internal clock) pushes the current SB ($FF01) into the buffer and clears bit 7 of SC at once (documented simplification: transfer completes instantly; the exact duration is a later serial task; add a line in open_questions.md).
2. A full buffer drops new bytes (document it in a comment). SC reads keep the unused bits as the reset value already wired in bus.rs.
3. `Bus::take_serial(&mut self, out: &mut [u8]) -> usize` drains the buffer; `Dmg::take_serial_output(&mut self, out: &mut [u8]) -> usize` forwards to it.
4. Tests: $FF01=0x41 then $FF02=0x81 gives one captured byte 0x41 and bit 7 cleared; external-clock value 0x80 captures nothing; drain empties; overflow drops.
