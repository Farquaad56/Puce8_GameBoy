# C01_34 - Timer: DIV, TIMA, TMA, TAC counting
Role: CODE
Goal: Timer registers wired on the bus and counting.
Prerequisites: C01_33
Read (max 3 files, give line ranges): docs/annexes/notes/ (ls | grep -i timer; read that note only, grep first); docs/annexes/decisions.md (A_01 chip order)
Write only in: crates/puce8gb-core/src/timer.rs, crates/puce8gb-core/src/bus.rs, crates/puce8gb-core/src/machine.rs, crates/puce8gb-core/src/lib.rs
## Work
1. timer.rs: internal 16-bit counter, DIV = its upper byte, writing DIV resets the counter; TAC enable + 4 clock selects; TIMA increments on the falling edge of the selected counter bit (note). Values from the note, never from memory.
2. Advance one dot per Machine::tick() in the chip order of A_01. Registers on the bus at their addresses (bus.rs currently holds raw I/O bytes: route DIV/TIMA/TMA/TAC to the timer).
3. Tests: DIV increments at the documented rate; write resets it; TIMA rate for each TAC value; disabled timer does not count.
