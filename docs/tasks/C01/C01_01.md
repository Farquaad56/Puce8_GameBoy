# C01_01 - CPU clean slate: skeleton, engine contract, test helper
Role: CODE
Goal: Old CPU deleted. New Cpu struct and tick() that fetches and records every opcode as unimplemented.
Prerequisites: E02_01
Read (max 3 files, give line ranges): docs/annexes/decisions.md (section C_00 only); crates/puce8gb-core/src/cpu/registers.rs (head -40)
Write only in: crates/puce8gb-core/src/cpu/, crates/puce8gb-core/tests/
## Work
1. Delete crates/puce8gb-core/src/cpu/opcode_table.rs and crates/puce8gb-core/tests/e02_03_cpu_tests.rs (git rm). Rewrite cpu/mod.rs from scratch. Keep cpu/registers.rs untouched.
2. Keep EXACTLY this public surface (machine.rs and the E01 tests use it): pub fields a f b c d e h l sp pc; `Cpu::default()`; `Cpu::reset(checksum: u8) -> Cpu` (delegates to Registers::reset); `Cpu::regs() -> Registers`. Derive Default, Clone, Copy, Debug, PartialEq, Eq.
3. Add the private engine state of decision C_00 (opcode, step, two latches, cb flag, unimplemented record). No InstrState, no OpInfo, no opcode table.
4. `pub fn tick(&mut self, bus: &mut Bus)` per C_00: step 0 = fetch of the opcode at PC (one bus read, PC+1), then the group dispatch chain (empty for now). An opcode that no group claims is recorded in `unimplemented: Option<(u8, u16)>` (opcode, address of the opcode byte), costs its fetch M-cycle only, and the engine returns to step 0. Do not panic.
5. Accessors: `pub fn at_boundary(&self) -> bool`, `pub fn unimplemented(&self) -> Option<(u8, u16)>`.
6. Test helper, `#[cfg(test)] pub(crate) mod testutil` in cpu/: `new_bus() -> Bus` (32 KiB zero ROM), `exec(cpu: &mut Cpu, bus: &mut Bus, code: &[u8]) -> u32` (writes the bytes at $C000 through bus.write, sets PC=$C000, ticks until at_boundary() again and returns the tick count; assert on a runaway > 64 ticks, never a silent cap).
7. Tests: at_boundary() true after reset; reset values unchanged (A=$01 etc. via Cpu::reset(0)); an unknown opcode is recorded with its address and costs exactly 1 tick; PC advanced by 1; F low nibble is 0.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm (open_questions.md).
- Name every unit test fn starting with `c01_01_` (the check filters on it).
- One tick = one M-cycle = AT MOST ONE bus access (decision C_00). Hardware arithmetic with wrapping_* only. No allocation in tick().
- A test is changed only if it contradicts the notes, never to make it pass. Never disable a test.
- cpu/registers.rs may only get ADDED helpers: its e02_01_ tests must keep passing.
