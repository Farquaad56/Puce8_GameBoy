# C01_33 - HALT, HALT bug, STOP, illegal opcodes
Role: CODE
Goal: Low-power states and the 11 illegal opcodes.
Prerequisites: C01_32
Read (max 3 files, give line ranges): docs/annexes/notes/02b_cpu_interrupts.md (grep HALT, STOP); docs/annexes/notes/02a_cpu_core.md (grep illegal); docs/annexes/decisions.md (C_00)
Write only in: crates/puce8gb-core/src/cpu/
## Work
1. HALT in `cpu/halt.rs`: while halted, one M-cycle per tick with no PC change; wake when (IE & IF & $1F) != 0 regardless of IME; if IME=1 the interrupt is served next (C01_32 dispatch), else execution resumes after HALT.
2. HALT bug: IME=0 and an interrupt already pending when HALT executes => the next opcode byte is read twice (PC not incremented once). Source: note 02b. If the note is not precise, UNKNOWN - to confirm and let the ROM halt_bug (C01_41) decide.
3. STOP: consume the second byte; behaviour per note 02b (UNKNOWN items go to open_questions.md). No wake-up source exists yet: keep it simple and documented.
4. The 11 illegal opcodes (list in note 02a): the CPU locks (no PC change, no bus access beyond the fetch already done). They are NOT recorded as unimplemented.
5. Tests: HALT with IME=1 / IME=0, wake-up, halt bug read twice, each illegal opcode locks.
## Rules
- Identifiers and comments in English, ASCII only. Zero invention: unknown => UNKNOWN - to confirm (open_questions.md).
- Name every unit test fn starting with `c01_33_` (the check filters on it).
- One tick = one M-cycle = AT MOST ONE bus access (decision C_00). Hardware arithmetic with wrapping_* only. No allocation in tick().
- A test is changed only if it contradicts the notes, never to make it pass. Never disable a test.
- cpu/registers.rs may only get ADDED helpers: its e02_01_ tests must keep passing.
- FORBIDDEN: a test that ticks a REAL opcode of another group and expects it to be unimplemented (it breaks when that group is implemented and `done` replays old checks). To test the unimplemented path use `record_unimplemented` directly (core tests) or `Cpu::debug_set_unimplemented` (other crates). "Implement ONLY the LIST" means: write no code for other opcodes, not: write tests for them.
