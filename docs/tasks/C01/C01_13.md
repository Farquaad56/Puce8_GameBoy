# C01_13 - ADD, ADC, SUB, SBC
Role: CODE
Goal: 8-bit arithmetic on A.
Prerequisites: C01_12
Read (max 3 files, give line ranges): docs/annexes/notes/02a_cpu_core.md (grep first); docs/annexes/notes/02c_cpu_opcodes_src.md (grep the mnemonics); docs/annexes/decisions.md (section C_00)
Write only in: crates/puce8gb-core/src/cpu/
## Work
1. grep -n "## C_00" docs/annexes/decisions.md, then read only that section (engine contract: step, fetch, done(), latches).
2. For each mnemonic of the LIST below, grep -n -i it in note 02c: take the byte length and M-cycle count from the note. Write them in the tests as expected values, with the note name in a comment.
3. Implement in `cpu/alu_add.rs`: `impl Cpu { pub(super) fn exec_alu_add(&mut self, bus: &mut Bus) -> bool }`. It returns true when the current opcode belongs to this group (decide by opcode bit fields, see C_00) and false otherwise. Add ONE line for it in the dispatch chain of cpu/mod.rs.
4. Tests with the `exec` helper (C_00): per family check the tick count, register or memory result, flags, PC advance. Add at least one edge case (wrap-around or flag boundary).
5. Implement ONLY the LIST. Every other opcode stays unimplemented (the engine records it).
## LIST
ADD A,r; ADD A,(HL); ADD A,n; ADC A,r|(HL)|n; SUB A,r|(HL)|n; SBC A,r|(HL)|n. Put the flag arithmetic in pure functions `add8(a, b, carry) -> (u8, flags)` and `sub8(...)`, unit-tested alone (half-carry and carry boundaries, ADC/SBC with carry in).
